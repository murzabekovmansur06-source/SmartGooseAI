🦆 **BETA(RAG МОЖЕТ ВЫДАВАТЬ ОШИБОЧНЫЕ ОТВЕТЫ)**
SmartGooseAI -  Мод для Desktop Goose с RAG-поиском и опциональной поддержкой ИИ

| Функция | Описание |
|---------|----------|
| RAG-поиск | Гусь ищет ответы по вашей базе знаний (встроенные датасеты + ваши данные) |
| ИИ-режим | Поддержка любых моделей: DeepSeek, Qwen, GPT и другие |
| Свои датасеты | Добавляйте свои данные через other_dataset.json(илт просто создавая/закидывая json/jsonl файлы в папку knowledge |
| Окно поверх игры | Чат не перекрывается и не прячется за Unity |
| Горячие клавиши | Ctrl+Alt+N для вызова окна в любой момент |

| Шаг | Установка |
|-----|-----------|
| 1 | Скачайте SmartGooseAI.dll и Newtonsoft.Jsonl.dll |
| 2 | Создайте папку knowledge |
| 3 | Поместите файл в папку Assets/Mods/SmartGooseAI/ |
| 4 | Закиньте датасеты(dataset_part1.jsonl,dataset_part2.jsonl,full_articles.jsonl и learned_data.jsonl) в папку knowledge  |
| 5 | Запустите Desktop Goose |
| 6 | Нажмите Ctrl+Alt+N(или нажмите 2 раза на синею кнопку I рядом с часами  — появится окно чата(или ^ - потом I ДВА РАЗА)) |

> Примечание: конфиг config.json создастся автоматически при первом запуске.

| Параметр | Тип | Описание |
|----------|-----|----------|
| EnableAI | true/false | Включить генерацию через ИИ (иначе только RAG) |
| model | string | Название модели (например, deepseek-chat) |
| SystemPrompt | string | Роль гуся (например, «Ты хакер из Roblox») |

 **Пример config.json**:
" { "EnableAI": false, "model": "deepseek-chat", "SystemPrompt": "Ты умный гусь-помощник" } "

 Добавление своих данных:
 1. Создайте в папке knowledge файл other_dataset.json(или под другим названием)
 2. Заполните по шаблону (см. пример ниже) 
 3. Гусь будет искать в ваших данных наравне с основными


 **Пример other_dataset.json**:
 [ {"question": "Что такое RAG?", "answer": "Retrieval-Augmented Generation — поиск по базе знаний"}, 
 {"question": "Как работает кеширование?", "answer": "Кеш хранит ответы, чтобы не обращаться к модели повторно"} ] 

| Файл | Назначение |
|------|------------|
| MainMod.cs | Точка входа, инициализация WinForms-потока |
| TrayContext.cs | Иконка в трее, управление окном |
| ChatForm.cs | Окно чата (ввод, вывод, история) |
| RAGEngine.cs | Гибридный поиск + реранкинг |
| other_dataset.json | Пользовательские данные (внешний файл) |

| Режим | Что делает |
|-------|------------|
| RAG only (EnableAI = false) | Быстрый поиск по датасетам, без генерации |
| ИИ + RAG (EnableAI = true) | Модель генерирует ответ на основе найденного контекста |
